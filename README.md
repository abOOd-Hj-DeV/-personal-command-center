# مركز القيادة الشخصي — Personal Command Center

لوحة تحليلات وإنتاجية شخصية مستوحاة من إحصاءات Codeforces ورسومه البيانية —
تتبّع يومي، خريطة نشاط، رسم بياني للتقدّم، مشاريع وأهداف، ومراجعة أسبوعية.
يعمل بالكامل دون خادم: بياناتك محفوظة محليًا في متصفحك (IndexedDB) وتعمل أوفلاين.

## التقنيات

- Vite + React 18 + TypeScript + Tailwind CSS v4
- Recharts (الرسم البياني) · Dexie/IndexedDB (التخزين المحلي) · vite-plugin-pwa (التثبيت والعمل أوفلاين)
- Vitest + fake-indexeddb (الاختبارات)

## التشغيل محليًا

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # إنتاج → dist/
npm run preview    # معاينة بناء الإنتاج
npm test           # الاختبارات
npm run typecheck  # فحص TypeScript
```

## النشر على Vercel

1. ادفع الريبو إلى GitHub.
2. في vercel.com: **Add New → Project → Import** الريبو. `vercel.json`
   مضبوط مسبقًا (framework: vite, `npm ci`, `npm run build`, `dist` +
   rewrite للـ SPA) — اضغط Deploy فقط.
3. كل push على `main` ينشر تلقائيًا.

## الاستخدام على الجوال

افتح رابط Vercel من متصفح الجوال ثم **قائمة المتصفح ⋮ ← "إضافة إلى الشاشة
الرئيسية"** — يُثبَّت كتطبيق PWA ويعمل أوفلاين بالكامل بعد أول زيارة.

## نموذج البيانات (IndexedDB)

| الجدول | المحتوى |
|---|---|
| `activities` | إدخال يومي: تاريخ، فئة، مشروع؟، دقائق، إنجاز، ملاحظة |
| `dayRecords` | تقييم اليوم الرباعي (مقترح آليًا أو يدوي) + تأمل |
| `categories` | الفئات (الإنجليزية، CEnT-S، مشاريع، تعلم تقني، عمل حر، شخصي + مخصصة) |
| `projects` / `milestones` | مشاريع: حالة، أولوية، خطوة تالية، ملاحظات، معالم |
| `weeklyReviews` | مراجعة أسبوعية خفيفة لكل أسبوع |
| `meta` | تفضيلات (ثيم، لغة، أهداف أسبوعية، حد اليوم النشط) |

كل سجل يحمل `updatedAt`. التصدير JSON كامل من الإعدادات، والاستيراد يدمج
مع التحقق — عند التكرار يفوز السجل الأحدث، ولا يفقد استيراد بيانات أحدث.
استخدم التصدير/الاستيراد لنقل بياناتك بين اللابتوب والجوال.

## فلسفة المقاييس (مهم)

- **قابل للقياس**: دقائق التركيز، عدد المهام المنجزة — بيانات خام.
- **مؤشر محسوب**: مؤشر الاستمرارية = أيام نشطة ÷ أيام الفترة × 100
  (يوم "نشط" = ≥ `activeDayMinutes` دقيقة أو مهمة منجزة واحدة).
- **درجة جودة اليوم** = تقييمك الرباعي (صعب=1 … استثنائي=4). النظام يقترح
  التصنيف من قواعد قابلة للضبط — لا يعتمد على عدد المهام فقط — ويمكنك دائمًا
  تجاوزه يدويًا.
- لا يوجد "تقييم مهارة" وهمي. كل مركّب موثّق بالصيغة داخل الواجهة.

## المسارات الحرجة المختبرة (`npm test` — 27 اختبارًا)

إنشاء/تعديل سجلات اليوم، استمرار التخزين بعد "إعادة فتح" قاعدة البيانات،
حسابات الرسم البياني والسلاسل الزمنية، خريطة النشاط، التواريخ والمناطق
الزمنية، اقتراح تصنيف اليوم، التصدير/الاستيراد مع dedupe والتحقق.

## قيود معروفة

- لا مزامنة تلقائية بين الأجهزة (حسب الطلب — النقل عبر تصدير/استيراد JSON).
- خريطة النشاط تعرض آخر ~6 أشهر؛ الرسم البياني يدعم "كل الفترة".
- حذف فئة مخصصة لا يحذف إدخالاتها (تبقى ظاهرة بدون لون).
